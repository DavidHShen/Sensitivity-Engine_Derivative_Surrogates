# Data availability

The manuscript uses daily S&P 500 levels from Stooq together with FRED Treasury and volatility-index series.

## Files required by the code

```text
spx_stooq.csv
DGS3MO.csv
DGS2.csv
DGS10.csv
VIXCLS.csv
VXVCLS.csv
```

## Why raw files are not included

The repository does not redistribute third-party index or macroeconomic data. Users are responsible for obtaining data under the providers' applicable terms and for determining whether their intended use permits storage, processing, publication, or redistribution.

## Provider-vintage limitation

Historical datasets can be revised, renamed, shortened, or replaced. A file with the expected name and columns is sufficient to run the code, but it is not sufficient to establish numerical equivalence to the manuscript input.
